# Reviewer access draft

The production demo does not exist. Do not submit these instructions until the
demo is deployed and passes the public smoke test.

## Play Console application access

No login is needed.

1. Open Ichoi and tap **I accept**.
2. Tap **Connect to demo server**.

The application connects to `https://demo.ichoi.invalid` and opens the library.
Select an album or audiobook, then tap its play control. The demo contains no
account requirement and no reviewer credential.

## Required replacement

Replace `https://demo.ichoi.invalid` with the approved production URL after the
demo is deployed. Confirm that the path needs no authentication, geographic
exception, VPN, or private network. Save the date, application version, server
version, and public smoke-test result with the release evidence.
