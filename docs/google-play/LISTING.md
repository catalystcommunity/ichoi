## Application name

Ichoi

## Short description

Play audio from an Ichoi server that you or someone you trust operates.

## Full description

Ichoi is a native client for an Ichoi music and audiobook server. Add the URL of
your server, sign in when the server requires it, browse its library, and play
audio on your device.

The application does not include music or audiobooks. You must connect it to an
Ichoi server. The server operator supplies the media and controls the accounts,
playlists, reports, logs, and retention rules on that server.

You can use more than one server profile. Secure connections are the default.
The application can use a private-network plain connection only after you read
and accept a warning.

Ichoi is always free. It has no advertisements, purchases, subscriptions,
analytics, remote crash reporting, or donation function. The source code is
available under the Apache License, Version 2.0.
