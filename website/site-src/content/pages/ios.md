<p class="eyebrow">iOS</p>
<h1>Use the server you choose.</h1>
<ol><li>Install Ichoi from a trusted build source.</li><li>Read and accept the terms before you create a playlist.</li><li>Select <strong>Add my server</strong> and enter the HTTPS URL from the server operator.</li><li>Sign in, browse the library, and start playback.</li></ol>
<h2>Account controls</h2><p>Ichoi stores the session in the device Keychain. Use <strong>Settings → Sign out</strong> to remove it. Use <strong>Settings → Delete account</strong> and enter your current handle to request deletion from the selected server.</p>
<p>When deletion fails, the client keeps the session and shows the server URL. Contact that server's administrator. The Ichoi developer cannot access an independently operated server.</p>
<p>See the <a href="privacy.html">privacy policy</a> and <a href="support.html">support page</a>.</p>
