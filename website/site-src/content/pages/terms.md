<p class="eyebrow">Terms</p>
<h1>Use Ichoi with care.</h1>
<p>By using Ichoi, you agree to follow the rules of the server that you select and to use media that you have the right to access.</p>
<h2>Prohibited content and behavior</h2>
<ul><li>Do not upload, provide, or share media without the needed rights.</li><li>Do not use a server to threaten, harass, abuse, or impersonate another person.</li><li>Do not publish illegal, exploitative, or privacy-invasive content.</li><li>Do not bypass access controls, attack a server, or send requests that can harm its operation.</li><li>Do not submit false, abusive, or repeated reports.</li></ul>
<h2>Reports</h2><p>A client can report a playlist or an account. The report form provides these reasons: <strong>objectionable content</strong>, <strong>harassment</strong>, <strong>spam</strong>, and <strong>other</strong>. You can add optional details. The selected server operator receives and reviews the report, sets its status, and controls any removal. Ichoi does not decide or enforce a report on an independent server.</p>
<h2>Playlists</h2><p>You must accept these terms before you create a playlist. The server derives playlist ownership from your authenticated account. A client cannot set another owner.</p>
<h2>Licence and availability</h2><p>Ichoi is provided under Apache-2.0. The project can change or stop the clients or website. Each server can set its own availability and rules.</p>
