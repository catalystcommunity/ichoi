<p class="eyebrow">Android</p>
<h1>Connect in a few steps.</h1>
<ol><li>Install Ichoi from a trusted build source.</li><li>Read and accept the terms before you create a playlist.</li><li>Select <strong>Add my server</strong>.</li><li>Enter the HTTPS URL given by your server operator. The client checks the connection before sign-in.</li><li>Sign in, browse the library, and start playback.</li></ol>
<h2>Your session and account</h2>
<p>The client stores the session token in secure app storage. Select <strong>Settings → Sign out</strong> to remove it. Select <strong>Settings → Delete account</strong> and enter your current handle to ask the selected server to delete the account.</p>
<p>If deletion fails or the server does not support it, the client keeps your session and shows the server URL. Contact that server's administrator.</p>
<h2>Reports</h2><p>Use the report action on a playlist or account. Select one of the four reasons and add optional details. The selected server operator reviews the report.</p>
