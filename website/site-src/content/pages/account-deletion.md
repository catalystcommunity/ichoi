<p class="eyebrow">Account deletion</p>
<h1>Delete your account from its selected server.</h1>
<p>Ichoi accounts belong to the server that you selected. The Ichoi developer cannot access or delete accounts on independently operated servers.</p>
<h2>Use a web browser</h2>
<ol><li>Open the selected server URL in a browser. Use the same server URL shown in the Ichoi client.</li><li>Sign in to the account.</li><li>Open <strong>Settings → Delete account</strong>.</li><li>Enter your current account handle, then confirm.</li><li>Wait for the server to report success. Do not sign out first if you need the session for this request.</li></ol>
<h2>If deletion fails</h2>
<p>The client keeps the session when deletion fails or the response is unknown. Copy the server URL shown by the client and contact that server's administrator. Support contact for this project: <a href="mailto:support@ichoi.invalid">support@ichoi.invalid</a>. This address is a placeholder until approved.</p>
<p>If the server does not implement deletion, only that server's administrator can provide the next step. The Ichoi developer cannot perform the operation for that server.</p>
