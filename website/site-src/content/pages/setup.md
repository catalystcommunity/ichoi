<p class="eyebrow">Setup</p>
<h1>Connect the parts you control.</h1>
<p class="lead">Ichoi needs a compatible server. The server stores the account and media data. The client stores only the session that it needs for access.</p>
<div class="cards"><article class="card"><h2>Use a server</h2><p>Ask the server operator for its HTTPS URL and an account. Then follow the <a href="android.html">Android</a> or <a href="ios.html">iOS</a> guide.</p></article><article class="card"><h2>Run a server</h2><p>Install the server, add media that you can lawfully provide, and protect its URL, database, and secrets. Read the <a href="server.html">server setup guide</a>.</p></article><article class="card"><h2>Need account help?</h2><p>The selected server controls the account. Use <a href="account-deletion.html">account deletion help</a> for the exact steps.</p></article></div>
<div class="notice"><strong>Important:</strong> Ichoi cannot recover an account or change data on an independently operated server.</div>
</article>
