<h1>Built in the open.</h1>
<p>Ichoi source code is available under the Apache License, Version 2.0. Read the repository licence and notice files for the complete terms.</p>
<p>The Ichoi clients do not include music recordings. Server operators supply media and must review the licence and attribution requirements for every recording before public use.</p>
<h2>Third-party components</h2><p>Release builds must include an approved inventory of third-party software and licences. This page does not approve recordings, music claims, or attribution claims. Contact <a href="mailto:support@ichoi.invalid">support@ichoi.invalid</a> for project questions.</p>
