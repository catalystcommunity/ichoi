iOS

Use the server you choose.

  1. Install Ichoi from a trusted build source.
  2. Read and accept the terms before you create a playlist.
  3. Select Add my server and enter the HTTPS URL from the server operator.
  4. Sign in, browse the library, and start playback.

Account controls

Ichoi stores the session in the device Keychain. Use Settings → Sign out to remove it. Use Settings → Delete account and enter your current handle to request deletion from the selected server.

When deletion fails, the client keeps the session and shows the server URL. Contact that server's administrator. The Ichoi developer cannot access an independently operated server.
