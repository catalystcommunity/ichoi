Setup

Connect the parts you control.

Ichoi needs a compatible server. The server stores the account and media data. The client stores only the session that it needs for access.

Use a server

Ask the server operator for its HTTPS URL and an account. Then follow the Android or iOS guide.

Run a server

Install the server, add media that you can lawfully provide, and protect its URL, database, and secrets. Read the server setup guide.

Need account help?

The selected server controls the account. Use account deletion help for the exact steps.

Important: Ichoi cannot recover an account or change data on an independently operated server.
