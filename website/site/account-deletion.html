Account deletion

Delete your account from its selected server.

Ichoi accounts belong to the server that you selected. The Ichoi developer cannot access or delete accounts on independently operated servers.

Use a web browser

  1. Open the selected server URL in a browser. Use the same server URL shown in the Ichoi client.
  2. Sign in to the account.
  3. Open Settings → Delete account.
  4. Enter your current account handle, then confirm.
  5. Wait for the server to report success. Do not sign out first if you need the session for this request.

If deletion fails

The client keeps the session when deletion fails or the response is unknown. Copy the server URL shown by the client and contact that server's administrator. Support contact for this project: support@ichoi.invalid. This address is a placeholder until approved.

If the server does not implement deletion, only that server's administrator can provide the next step. The Ichoi developer cannot perform the operation for that server.
