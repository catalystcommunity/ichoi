Terms

Use Ichoi with care.

By using Ichoi, you agree to follow the rules of the server that you select and to use media that you have the right to access.

Prohibited content and behavior

  • Do not upload, provide, or share media without the needed rights.
  • Do not use a server to threaten, harass, abuse, or impersonate another person.
  • Do not publish illegal, exploitative, or privacy-invasive content.
  • Do not bypass access controls, attack a server, or send requests that can harm its operation.
  • Do not submit false, abusive, or repeated reports.

Reports

A client can report a playlist or an account. The report form provides these reasons: objectionable content, harassment, spam, and other. You can add optional details. The selected server operator receives and reviews the report, sets its status, and controls any removal. Ichoi does not decide or enforce a report on an independent server.

Playlists

You must accept these terms before you create a playlist. The server derives playlist ownership from your authenticated account. A client cannot set another owner.

Licence and availability

Ichoi is provided under Apache-2.0. The project can change or stop the clients or website. Each server can set its own availability and rules.
