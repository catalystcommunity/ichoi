Privacy policy

Privacy at Ichoi

Last updated: 12 September 2026

This policy describes the Ichoi application and website operated by Catalyst Community. Privacy contact: privacy@ichoi.invalid. This contact is a placeholder until a person approves the address.

What the application sends

The application sends the server URL, sign-in data, session requests, browsing requests, playback requests, playlist actions, and reports to the server that you select. A report can include a playlist or account target, a selected reason, and optional details that you enter.

The application stores a session token in secure local storage. It does not use ads, analytics, remote crash reporting, purchases, subscriptions, or donation functions. It does not add a persistent media cache.

What the website receives

The static website does not provide an account or a server. Its web server can receive normal HTTP request data, such as an IP address, user agent, and requested path. The website operator controls server logs and retention. This site does not add advertising or analytics.

Selected server data

Each server operator controls the account, playlists, reports, media, logs, and retention for that server. The operator must publish its own notice and support process. Data goes only to servers that you select, subject to the requests that you make.

A selected server can store these data:

  • Your LinkKeys subject, handle, display name, role, account creation time, session token hash, and session expiry.
  • Your audiobook position for each track.
  • Your private playlists and public playlists that you create.
  • Your shared device registrations.
  • Reports that you submit and reports that target your account.
  • Your IP address in server logs. The server operator sets the log retention period.

Account deletion removes your account, sessions, audiobook progress, private playlists, shared device registrations, submitted reports, and reports that target your account. Public playlists remain, but the server removes their owner link.

Your choices

You can sign out to remove the local session. You can request account deletion from the selected server by following the account deletion instructions. Contact the selected server operator for server data questions.

Changes

We will update this page when the application or website data use changes. Check the date at the top of this page.
