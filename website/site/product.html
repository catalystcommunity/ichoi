Product

Listen from a server you choose.

Ichoi connects to a compatible server. It lets you browse available music, play it, and manage your account on that server.

What Ichoi provides

  • Native Android and iOS clients.
  • Server profiles for servers that you choose.
  • Account sign-in and secure session storage.
  • Browsing and streaming from the selected server.
  • Playlist and account reporting to the selected server.

What Ichoi does not provide

Ichoi does not include music, host accounts, or supply a default music catalogue. You supply the server and media. A server operator decides which media is available and how long server data stays on the server.

Ichoi is always free. It has no ads, purchases, subscriptions, analytics, remote crash reporting, or donation functions. It is available under the Apache-2.0 licence.
