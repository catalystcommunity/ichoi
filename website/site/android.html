Android

Connect in a few steps.

  1. Install Ichoi from a trusted build source.
  2. Read and accept the terms before you create a playlist.
  3. Select Add my server.
  4. Enter the HTTPS URL given by your server operator. The client checks the connection before sign-in.
  5. Sign in, browse the library, and start playback.

Your session and account

The client stores the session token in secure app storage. Select Settings → Sign out to remove it. Select Settings → Delete account and enter your current handle to ask the selected server to delete the account.

If deletion fails or the server does not support it, the client keeps your session and shows the server URL. Contact that server's administrator.

Reports

Use the report action on a playlist or account. Select one of the four reasons and add optional details. The selected server operator reviews the report.
